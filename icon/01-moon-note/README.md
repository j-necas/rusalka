# Rusalka — moon and note (01)

The chosen direction: a dark blue crescent joined to an eighth note, with its reflection on the water.
Clean vector artwork following the approved design 01.

- `logo.svg` — horizontal logo with the name, transparent background. The lettering is converted to outlines.
- `symbol.svg` — the symbol on its own with a light blue water surface, transparent background.
- `symbol-mono.svg` — the symbol in a single colour, also suitable for small sizes.
- `icon.svg` — the icon on a light blue rounded background, the symbol in one colour for better contrast.
- `icon-1024.png`, `icon-512.png`, `icon-192.png`, `icon-32.png` — raster icons.
- `logo.png`, `symbol.png` — transparent raster exports.
- `overview.png` — an overview of all variants.

Colours: ink blue `#1F4C78`, water blue `#B5D7ED`, icon background `#CFE2F2`.
Wordmark: Atkinson Hyperlegible Next ExtraBold, the same typeface as the app (SIL OFL; licence in
`static/vendor/fonts/OFL.txt`). The SVGs are self-contained: no external images, fonts or filters.

The app and website icons are built from these files.
